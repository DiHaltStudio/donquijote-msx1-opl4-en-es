# Don Quijote / Don Quixote — MSX-DOS + OPL4 v1.0

The classic 1987 adventure with OPL4 narration, fast picture loading and both
parts joined together. Spanish and English text, commands and voices are
included in one package.

- Run QUIJOTE for Spanish or QUIXOTE for English.
- MSX1 and later; MSX-DOS 1, MSX-DOS 2 and Nextor.
- 512 KiB mapper RAM and OPL4 with 2 MiB wave RAM.
- MegaFlashROM SCC+ SD or an equivalent interface compatible with the loader.
- Illustrated player manuals in both languages.

Copy all files in SD/ together. Under DOS2/Nextor, enter their directory; under
DOS1, place them in the drive root. Press RETURN at the initial password prompt
to begin part one, or enter the classic password to begin part two.

Original game: Dinamic Software, 1987. Unofficial adaptation and homage by
DiHalt Studio, 2026. Original game elements belong to their respective holders.
